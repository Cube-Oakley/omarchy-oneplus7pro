# Standard Omarchy palettes

These `colors.toml` files were copied unchanged from the development host's
`/usr/share/omarchy/themes/` (Omarchy 4.0.0.alpha) on 2026-09-17.
Upstream: https://github.com/basecamp/omarchy . License: `LICENSE.omarchy`.

They provide a bring-up fallback while the handset lacks the full Omarchy
installation. Installed Omarchy themes and user theme directories take
precedence. No theme scripts are bundled or executed.

The accompanying Omarchy branding assets under `../fastfetch/` came from the
same installation and are covered by the upstream notice as well.
