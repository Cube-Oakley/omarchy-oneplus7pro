# GS201 ACPM v13 — hardware-tested source checkpoint

Image D booted on Pixel 7 Pro and completed bounded firmware frequency and
seven-group temperature queries. No frequency-setting or GPU rendering is tested.
See [the bring-up record](../../docs/acpm-bringup-20260925.md).

`native-bringup-v13.patch` is a **cumulative** snapshot against `kernel-base.txt`.
Apply it to a clean copy of that base. It includes earlier native USB/display
bring-up and the embedded test overlay; do not stack it on v11 or the historical
`acpm-foundation` patches. `kernel.config` is the tested image D configuration.
The generated byte-array header is preserved exactly, including its formatting.
This archive is not an upstream submission series.

Use the project build helper and pinned BusyBox/base-image inputs documented in
the earlier native checkpoints. Overlay source is also copied here; active source
is `mainline/pixel-acpm-overlay.dts`. No device writes occur during compilation.
